## できること

- **選手** … 名前・チーム名で検索。鹿児島は先頭に⭐チップ（日付ボタンでその日に泳ぐ人だけ）。種目の行にはタイムの上に実施日を小さく表示。
- **種目** … 種目ごとの出場者をエントリータイム順に。◀ ▶ で前後の種目へ。
- **日程** … 種目一覧。日付で絞り込める。
